# 🫖 Карточка товара

Тестовое задание: вёрстка карточки товара по образцу.

## Запуск
Склонировать или скачать репозиторий.  
Открыть index.html в браузере.  
Сборка и установка зависимостей не требуются.  

## Реализовано
- адаптивная вёрстка карточки товара;
- выбор фасовки;
- изменение артикула и цены при выборе фасовки;
- отображение текущей выбранной фасовки.
